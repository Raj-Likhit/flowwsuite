Critical Severity pdf-engine

After: Async/Await with Guaranteed Finally Block
                flowchart TD
                  A[await canvas.loadFromJSON JSON] --> B[Promise Resolves All Objects]
                  B --> C[Rescale Loaded Objects to Viewport]

Failure Mechanism: In Fabric v7, loadFromJSON(json, reviver) returns a Promise<Canvas>. Passing an inline callback as the second argument treats it as the reviver function. When an empty page or blank state is loaded, zero objects exist, so the reviver is never executed. isRestoringRef.current remains locked at true indefinitely, silently swallowing all subsequent user drawing mutations.

Remediation: Convert all three loadFromJSON invocations in useFabricCanvas.ts to promise resolution (await or .then()) wrapped in a finally block that guarantees isRestoringRef.current = false.

5. Production Dependency CVEs & LAN Server Exposure (Issue #5)

High / Critical Vulnerabilities security-hygiene
Vite Config: vite.config.ts (line 64: server.host: true)
Audit Status: 32 vulnerabilities (21 high) in package-lock.json

Dev Server LAN File Exposure: In vite.config.ts, server: { host: true } binds the local development server to 0.0.0.0. Coupled with known Vite dev-server file-read advisories, any device on the same local network (Wi-Fi) can read arbitrary files from the developer's computer. Remediation: Default host to false (binding strictly to loopback 127.0.0.1).

Vulnerable Core Dependencies: pdfjs-dist has a high-severity vulnerability allowing arbitrary JavaScript execution via malicious PDF structures. react-router dependencies contain open high-severity advisory CVEs. Remediation: Update package resolutions and bump direct dependencies to patched security releases.

Tech Stack Architecture & Rationale

For this architectural and remediation blueprint, we selected Tailwind CSS, Mermaid 11 (ESM), and Semantic HTML5 with CSS Custom Properties for the following reasons:

  • Tailwind CSS (CDN) Enables strict adherence to an 8px spacing grid without requiring an external build step, guaranteeing portable inspection in any browser or environment.
  • Mermaid 11 ESM Renders reactive, client-side SVG sequence and flow diagrams directly from human-readable text specifications, providing visual before/after contrast for technical reviewers.
  • CSS Custom Properties Decouples color tokens into variables (--bg-page, --accent-danger, etc.), facilitating seamless theme transitions and accessible dark/high-contrast modes.
  • Accessibility Landmarks Employs HTML5 semantic landmarks (header, main, article, section, nav) and prefers-reduced-motion overrides for WCAG 2.1 AA compliance.
